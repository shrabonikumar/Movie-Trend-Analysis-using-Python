#  TMDB 5000 Movie Dataset Analysis | Python Project

This project involves the exploratory data analysis (EDA) of the TMDB 5000 Movie Dataset using Python. The goal is to uncover patterns and insights about movie revenues, genres, popularity, budgets, and cast influence to better understand what makes a movie successful.

## Project Overview :

This project walks through:
- Loading and cleaning raw movie and credit data
- Combining datasets using pandas
- Performing exploratory data analysis (EDA)
- Creating visualizations with matplotlib and seaborn
- Drawing insights related to:
  - Revenue vs. Budget
  - Popularity and Vote Average
  - Most common genres
  - Top earning directors and actors


Key columns analyzed:
- `title`, `genres`, `budget`, `revenue`, `runtime`
- `vote_average`, `popularity`, `release_date`
- `cast`, `crew`, `production_companies`

## Tools Used :

- Python
- pandas
- matplotlib
- seaborn

##  Key Insights :

- Certain genres like Action and Adventure dominate high revenue brackets.
- Budget has a strong correlation with revenue — big budget often means big returns.
- A small number of directors and actors consistently appear in top-performing films.
- Popularity score doesn't always align with critical acclaim (vote average).



##  Learnings :

- Data cleaning and merging real-world messy datasets
- Visualizing movie industry data with clarity
- Asking and answering analytical business questions
